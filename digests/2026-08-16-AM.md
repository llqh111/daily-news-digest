**为何有价值**：契合读者两大兴趣交集：MCP/AI Agent 与 WASM。常规 MCP 服务器都是静态工具集，hyper-mcp 允许用任意能编译到 WASM 的语言写插件，并通过 Docker Hub 等 OCI 注册表分发，还内置网络/文件/内存沙箱限制——相当于把 Agent 的工具生态变成了安全的插件平台。Star 数仅 880，说明远未被主流媒体放大，但架构思路可能是 MCP 生态的下一个演进方向（可插拔 + 沙箱 + 边缘部署）。
**为何被低估**：MCP 主流报道集中在 Anthropic 官方与大型厂商（OpenAI/Google）的动作，社区新兴的 WASM 化 MCP 运行时属于极客自留地，几乎没有科技媒体跟进。
🔗 https://github.com/hyper-mcp-rs/hyper-mcp

### 2. narsil-mcp：Rust 编写的高性能代码智能 MCP 服务器（90 个工具、32 种语言、安全扫描、调用图）
**为何有价值**：直接命中读者的 Rust 与 AI 编程双重兴趣。它在 MCP 协议下提供 90 个代码理解工具（调用图、安全扫描、跨语言分析），比 LangChain/LangGraph 那套通用 Agent 框架更贴近硬核开发者日常；Rust 实现意味着低延迟、内存安全，适合作为本地 AI coding agent 的代码后端。180 stars，属于『小而硬』的稀缺工具。
**为何被低估**：AI 编程工具的主流叙事被 Claude Code/Cursor 等封闭产品垄断，开源的 Rust 系 MCP 后端几乎无人报道，而它恰恰能让自建 agent 获得专业级代码分析能力。
🔗 https://github.com/postrv/narsil-mcp
