### 1. MCP Tool Poisoning Attacks —— Invariant Labs 一手安全披露
**为何有价值**：揭示 MCP（Model Context Protocol）的一个关键漏洞：攻击者可在 AI 模型可读、但用户 UI 不可见的工具描述中嵌入恶意指令，诱导模型读取 ~/.ssh/id_rsa、凭据等敏感文件并外泄。即使从不调用该工具，只要 MCP server 连接进上下文就会触发。对正在搭建 Agent/工具调用系统的读者来说，这是直接影响架构安全设计的实操情报；文中还提到已发出 30+ 相关 CVE，并给出隔离 MCP server、审查工具描述等缓解措施。
**为何被低估**：披露于 2025-04-01，主要在小众安全研究圈传播，主流科技媒体几乎未放大；大多数 MCP 客户端 UI 甚至不展示工具描述，导致开发者普遍不知情。
🔗 https://invariantlabs.ai/blog/mcp-security-notification-tool-poisoning-attacks

### 2. Systematic Analysis of MCP Security（arXiv 2508.12538）
**为何有价值**：对 MCP 生态做系统性安全分析的学术论文，超越单点漏洞披露，把 tool/context poisoning 等攻击面归纳为结构化分类，适合需要为 Agent 平台做威胁建模的硬核读者。
**为何被低估**：2025-08 上传的 arXiv 预印本，尚未被大众媒体覆盖，属于论文级一手内容，圈外曝光极低。
🔗 https://arxiv.org/html/2508.12538v1

### 3. DLSS 4 for Developers（Puget Systems 博客）
**为何有价值**：从开发者/引擎集成视角拆解 RTX 50 系列 DLSS 4（多帧生成、Transformer 模型）的实现细节，而非普通游戏评测，对关注游戏引擎与 GPU 技术的硬核 PC 玩家有额外认知增量。
**为何被低估**：发布在 Puget Systems 的开发者博客，被 CES 期间大量主流评测的声量淹没，真正讲集成原理的内容传播有限。
