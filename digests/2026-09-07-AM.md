🔗 https://alatirok.com/mcp-server-discovery/

### 2. modelcontextprotocol/modelcontextprotocol PR #1054: Add mcp.json discovery protocol
**为何有价值**：这是 mcp.json 发现协议的核心原始提案（GitHub PR #1054），包含讨论、合入状态与代码演进历史。对于深度关注 MCP 生态的技术读者，跟踪原始 PR 能比二手报道更早判断哪一方会成为事实标准，且能直接看到 Anthropic 等方在 review 中的态度——是评估标准走向的一手资料。
**为何被低估**：PR 层面的标准博弈极少被媒体放大，但对做 agent 基础设施/工具链的人是最关键信号；该 PR 已关闭但讨论过程揭示了协议的取舍（端点命名冲突、安全边界、与 DNS 发现的协同）。

### 3. IETF Internet-Draft: draft-morrison-mcp-dns-discovery-05（基于 DNS 的 MCP 服务器发现）
**为何有价值**：如果 agent 生态走向 DNS/SRV 记录发现 MCP 服务器，将重塑 MCP 的信任模型与部署方式。该草案定义了 SRV 记录指向 mcp:// URI 和/或 .well-known 路径的机制，是与 .well-known 方案完全不同的另一条路线；对关注 agentic 架构、网络安全与分布式系统的读者，这是理解下一代 MCP 基础设施演进的战略级情报，且草案中 DNSSEC 非强制这一设计取舍意味着巨大的中间人攻击面。
**为何被低估**：IETF 草案属于标准文档，不在大众科技媒体视野内；而 MCP 的 DNS 发现路线此前几乎无人讨论，目前仍在征求意见与协调阶段，越早阅读越有认知差。
🔗 https://datatracker.ietf.org/doc/html/draft-morrison-mcp-dns-discovery-05
