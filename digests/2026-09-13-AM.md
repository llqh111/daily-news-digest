### 1. MCP 2025-11-25 规范正式版：sampling 支持工具调用、URL 模式 elicitation、增量式 OAuth 授权
**为何有价值**：这是 Model Context Protocol 最新正式 spec 的变更日志一手来源。对正在做 Agent/工具调用/多智能体的读者而言，最关键是 SEP-1577 把 tool calling（tools + toolChoice 参数）加入了 sampling，意味着 server 可通过 sampling 让 client 的模型直接发起工具调用，显著改变 agent 编排方式；此外 SEP-1036 的 URL 模式 elicitation、SEP-835 的 WWW-Authenticate 增量 scope 授权、SEP-991 的 OAuth Client ID Metadata Documents 都直接影响 MCP 服务器的鉴权与交互设计。可直接指导自己的 MCP server / Agent 框架实现。
