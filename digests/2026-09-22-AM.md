## 💡 信息差侦察 · 今日认知增量

### 1. MCPMark: 压测真实复杂场景下 MCP 使用的严格基准
**为何有价值**：现有 MCP 基准偏'读多写少'、交互深度不足，MCPMark 由领域专家+AI Agent 协作构造高质量任务，每个任务有受控初始状态和自动验证脚本，强调丰富多样的环境交互与写操作，能真正区分哪些模型/Agent 在 realistic workflow 上能干活。对做 Agent 工程、选模型、评估工具调用链的读者是关键的评测标尺。
**为何被低估**：2025-09 的 arXiv 预印本，仅在 ar5iv/arXiv 流通，主流媒体未覆盖；MCP 生态评测仍属小众论文圈话题。
🔗 https://ar5iv.labs.arxiv.org/html/2509.24002

### 2. MCPToolBench++：蚂蚁集团的大规模 MCP 工具使用基准
**为何有价值**：工业界（蚂蚁集团）出品的大规模 MCP 工具调用评测集，相比学术小样本基准更贴近真实工具生态的规模与多样性，可用于横向对比不同 LLM 的工具调用能力，对 Agent/function calling 方向的模型选型和微调数据构建有直接参考价值。
**为何被低估**：以 PDF 预印本形式发布在 arXiv，无媒体放大，除非专门盯 MCP 评测否则很难发现。
🔗 https://arxiv.org/pdf/2508.07575v1.pdf

### 3. LiveMCPBench：Agent 能否在'工具海洋'中导航？
**为何有价值**：聚焦一个被忽视的真实痛点——当 MCP 工具数量爆炸式增长时，Agent 如何检索、筛选和选择正确工具。这把评测从'单工具调用'推进到'大规模工具发现与路由'，对构建可扩展 Agent 系统、工具 RAG、MCP 服务器治理的人有直接认知增量。
**为何被低估**：2025-08 arXiv 预印本，独立研究者主导，无大媒体或主流 AI 周报放大。
🔗 https://arxiv.org/html/2508.01780v1
